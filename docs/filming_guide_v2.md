# 撮影ガイド v2.0 (2025-11-03)

## 目的
Phase 0-4 適用ルールに基づき、再現性の高い計測動画を撮影するための基準と再撮手順を定義する。

## 推奨撮影条件
| 項目 | 推奨値 | 備考 |
|------|--------|------|
| 撮影距離 | 3.5 m ± 0.3 m | 被写体全身が 16:9 フレームに収まる距離 |
| 照度 | 500 lx 以上 | 影を避けるため、均一照明を推奨 |
| 解像度 | 1920 × 1080 (30 fps) | 以上を推奨。最低ライン: 1280 × 720 (30 fps) |
| 背景 | 単色・コントラスト低め | 動作抽出アルゴリズムの誤検出防止 |
| カメラ位置 | 腰〜胸の高さ | 被写体の重心が画面中央になる角度 |

## 再撮指標と手順
1. **品質評価 (QualityMonitor)**
   - `quality_score < 70` → 撮影者へ再撮指示
   - 影響要因: ランドマーク欠損、被写体の大きな揺れ
2. **QC Gate (Phase 0-4)**
   - `QC gate violation detected` WARN → 該当種目のみ再撮推奨
   - B4 骨盤水平 (>= 3.0) が初期対象
3. **再撮フロー**
   - ① 現場で撮影条件チェック → 距離 / 照度 / 解像度を再確認
   - ② 改善不可の場合は HQ へ連絡 (専用 Slack チャンネル)
   - ③ 代替環境での再撮 (予備スタジオ / 室内照明)
